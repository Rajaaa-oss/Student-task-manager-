
# Student Task Manager

## Project Overview
Student Task Manager is a simple web application
that helps students organize their daily study tasks.

## Objectives
- Make task management easy for students.
- Help students track completed tasks.
- Provide a simple and user-friendly interface.

## Features
- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- View total and completed task counts.
- Save tasks in browser Local Storage.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open index.html in a web browser.
3. Add and manage your study tasks.

## Future Enhancements
- Add task deadlines.
- Add task priorities.
- Organize tasks by subject.

## Conclusion
This project demonstrates the basic use of
HTML, CSS and JavaScript to build a useful
student productivity application.
